# Marcello Russo

Machine learning engineer, four years in production, the last year and a half on LLM infrastructure.
I build the parts around the model: routing, retrieval, evaluation, and the path from a commit to a
running service.

Currently AI/ML engineer at Netcaring. I built the agentic DevOps and LLM routing stack there: an
agent that carries a ticket to a merged pull request, the skills the team installs to use it, and the
release pipeline that runs each project's tests before the image is built. Part of that work was on
site at Leonardo, deploying production automation systems with the plant's operators and its
production manager. Before that I co-founded a software studio and built its client applications:
forensic audio analysis on GCP, and a navigation app for the Municipality of Argelato.
